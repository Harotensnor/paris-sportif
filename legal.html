👤 À propos

Paris-Sportif est un projet personnel et open-source édité par Théo Boulnois (particulier, France). C'est un outil éducatif et expérimental destiné à explorer l'efficacité d'un modèle data-driven sur des paris sportifs.

Le site n'est pas un opérateur de jeu, n'accepte aucun pari, ne traite aucune mise. Il publie des analyses statistiques sur des matchs à venir, sourcées depuis des bases publiques (ESPN, Sofascore, Jeff Sackmann, Football-Data.co.uk, MLB Stats API, NHL API, ClubElo, Open-Meteo, Winamax catalog).

Code source intégralement public et auditable : github.com/Harotensnor/paris-sportif. Toute personne peut vérifier comment le modèle est construit, comment les métriques sont calculées, et comment les pronos sont générés.

🔒 Politique de confidentialité

Ce qu'on stocke

Le site utilise uniquement le localStorage de ton navigateur pour conserver tes préférences (thème, page active, banque par défaut, alertes vues). Rien n'est envoyé à un serveur tiers. Pas d'analytics, pas de Google Analytics, pas de Meta Pixel, pas de Tag Manager, pas de Hotjar, pas de cookies tiers.

Ce que GitHub Pages voit (côté hébergeur)

L'hébergeur GitHub Pages enregistre techniquement ton adresse IP et ton User-Agent dans ses logs serveur, à des fins de sécurité (anti-DDoS, anti-abus). Ces logs sont gérés par GitHub Inc. selon leur privacy statement. Je n'ai aucun accès direct à ces logs.

Ressources externes chargées

La page charge ces ressources tierces (purement présentationnelles) :

  • a.espncdn.com — logos d'équipes (sourcés depuis ESPN scoreboard)
  • fonts.gstatic.com — Google Fonts (Inter), aucune donnée personnelle envoyée par le chargement de la font selon les FAQ Google Fonts

Aucune ressource publicitaire, aucun tracker marketing.

Effacer tes données

Tout est dans ton navigateur. Vide le localStorage du domaine harotensnor.github.io via les DevTools (F12 → Application → Local Storage → clear) ou utilise le bouton Reset complet sur la page Profil. Aucune copie distante n'existe.

Tes droits RGPD

Comme le site ne collecte aucune donnée personnelle côté serveur, les droits d'accès / rectification / effacement / portabilité s'exercent directement dans ton navigateur (localStorage). Pour toute question : passe par une issue GitHub.

🎰 Relation avec Winamax

Aucune affiliation. Aucune rémunération. Aucun accord commercial.

Le site cite Winamax comme bookmaker de référence pour deux raisons concrètes :

  • C'est l'opérateur que j'utilise personnellement (avec licence ANJ valide) — donc c'est la cote que je vois quand je teste mes pronos.
  • Leur catalogue est public, scrapeable, et permet de comparer la cote modèle à un marché réel sans payer un fournisseur d'odds.

Les liens "Voir sur Winamax" sont de simples liens vers la page publique du match. Pas d'identifiant d'affiliation, pas de tag de tracking, pas de redirection commerciale — vérifiable dans le code source de cette page (cherche winamax.fr).

Si à l'avenir une relation commerciale était mise en place, ce serait déclaré explicitement ici et à côté de chaque lien, avant toute mise en production. Cet engagement est pris en clair pour qu'il puisse être contesté si non respecté.

⚠️ Avertissement jeu responsable

Le site n'est pas un conseil financier. Le modèle vise ~60% de réussite sur le long terme (mesuré sur backtest), mais 3 à 5 défaites consécutives sont normales et n'indiquent pas un dysfonctionnement.

Réservé aux 18+. Les paris sportifs créent un risque réel d'isolement, d'endettement et de dépendance. La place du hasard est irréductible.
