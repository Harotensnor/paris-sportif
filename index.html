🔍 Comment ça marche

Le modèle ne cache rien. Chaque pick est expliqué par les composants qui l'ont produit, et la fiabilité est calibrée contre l'historique réel.

🔢

Multi-source pondéré

Marché (50%), Force (Elo / Sackmann surface), Forme L5/L10, Face-à-face, Météo, Compos, Goalie/Pitcher, Calibration ligue. Chaque sport a ses signaux propres.

🎯

Fiabilité calibrée

Tier lock, standard, lowconf, skip. Les "70% prédits" gagnent vraiment ~70% en backtest (gap < 5pp).

💰

Mises Kelly disciplinées

Kelly fractionnaire 0.25× cap 10% bankroll. Contient la variance court terme tout en captant la croissance long terme. Pas de "double-down après défaite".

📊

Backtest hebdo automatique

Cron du dimanche rejoue tous les picks contre les résultats réels via le vrai predictMatch(). ROI / WR / Brier / calibration mis à jour automatiquement.

⚖️

Honnêteté avant tout

Pas d'affiliation Winamax. Pas d'analytics par défaut. Pas de promesse de gains. Le hasard reste irréductible — 3-5 défaites d'affilée sont normales.

🔓

Code 100% public

Tu peux git clone et reproduire le backtest sur ta machine. Aucune boîte noire, aucun secret commercial. Voir le repo →
