# Reporting guidelines:
#
# 1. Open a private security advisory on the GitHub repo:
#    https://github.com/Harotensnor/paris-sportif/security/advisories/new
#
# 2. Or open a regular issue if the finding is non-sensitive
#    (e.g. broken link, stale documentation, missing alt attribute).
#
# 3. The site is a personal open-source project hosted on GitHub Pages.
#    No PII is collected server-side. Most "vulnerabilities" affect the
#    static pages or the Python pipeline scripts, not user data.
#
# 4. There is no bug bounty. Acknowledgments in commit log on resolution.
