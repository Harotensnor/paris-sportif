# TECH

  Hosting: GitHub Pages (HTTPS, no custom headers)
  Backend: GitHub Actions cron (refresh.yml every 5 min daytime)
  Pipeline: Python 3.11 (~30 fetcher / patcher scripts)
  Frontend: vanilla JS / vanilla CSS (no bundler, no framework, no build step)
  Static pages: hand-coded HTML (~17 KB each, indexable, JSON-LD)
  Service worker: offline cache + CACHE_VERSION on every deploy
  Tests: Playwright (e2e), Lighthouse CI (perf/SEO/a11y thresholds)
