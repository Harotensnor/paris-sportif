# ADR 014 — Historique append-only

## Context

Préserver les picks passés.

## Decision

Historique append-only. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Besoin de settlement et dédup.
