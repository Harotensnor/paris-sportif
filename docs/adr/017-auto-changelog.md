# ADR 017 — Changelog depuis commits

## Context

Éviter changelog oublié.

## Decision

Changelog depuis commits. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Qualité dépend des messages de commit.
