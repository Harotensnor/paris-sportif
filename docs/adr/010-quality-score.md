# ADR 010 — Score qualité composite

## Context

Ne pas confondre score et probabilité.

## Decision

Score qualité composite. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Il faut documenter les composantes.
