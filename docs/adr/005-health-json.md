# ADR 005 — `health.json` public

## Context

Exposer pipeline/data/model/ui/tests.

## Decision

`health.json` public. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Diagnostic lisible sans ouvrir les logs Actions.
