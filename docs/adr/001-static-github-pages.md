# ADR 001 — Conserver GitHub Pages

## Context

Le projet reste statique pour réduire coûts et maintenance.

## Decision

Conserver GitHub Pages. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Pas de backend user, contraintes fortes sur cache et génération.
