# ADR 016 — Wiki interne Markdown

## Context

Documentation proche du code.

## Decision

Wiki interne Markdown. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Nécessite génération de sitemap/index.
