# ADR 009 — `?debug=1`

## Context

Expose compteurs et raisons de rejet.

## Decision

`?debug=1`. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Aide à réconcilier tests et navigateur réel.
