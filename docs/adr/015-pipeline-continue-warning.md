# ADR 015 — Warnings non bloquants

## Context

Une source annexe ne doit pas casser le refresh.

## Decision

Warnings non bloquants. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Health doit être très clair.
