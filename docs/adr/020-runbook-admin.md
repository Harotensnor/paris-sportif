# ADR 020 — Runbook opérationnel

## Context

Théo doit pouvoir diagnostiquer vite.

## Decision

Runbook opérationnel. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Maintenir à jour avec pipeline.
