# ADR 007 — Shell ESM progressif

## Context

Ajouter modules natifs sans bundler obligatoire.

## Decision

Shell ESM progressif. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Migration douce depuis legacy-app.
