# ADR 013 — Cap top par match

## Context

Un match ne doit pas saturer le top.

## Decision

Cap top par match. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Autres marchés visibles en détail ou plus bas.
