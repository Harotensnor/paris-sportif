# ADR 004 — `data.js` comme source runtime

## Context

Le navigateur consomme un blob JS généré.

## Decision

`data.js` comme source runtime. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Simple pour GitHub Pages, gros fichier à surveiller.
