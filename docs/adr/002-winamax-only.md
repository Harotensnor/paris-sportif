# ADR 002 — Winamax comme bookmaker de référence

## Context

Les picks actionnables doivent être bookables chez Winamax.

## Decision

Winamax comme bookmaker de référence. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Moins de volume, plus de cohérence produit.
