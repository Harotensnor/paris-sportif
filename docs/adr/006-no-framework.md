# ADR 006 — Vanilla JS

## Context

Pas de framework SPA lourd.

## Decision

Vanilla JS. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Moins de dépendances, fichiers plus difficiles à organiser.
