# ADR 019 — Recherche docs locale

## Context

Index consultable sans serveur.

## Decision

Recherche docs locale. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Index statique à régénérer après docs.
