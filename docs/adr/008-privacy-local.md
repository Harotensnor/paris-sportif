# ADR 008 — Données utilisateur locales

## Context

Préférences, suivis, badges et exports restent navigateur.

## Decision

Données utilisateur locales. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Pas de compte multi-device.
