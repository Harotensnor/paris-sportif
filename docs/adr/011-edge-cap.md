# ADR 011 — Caps anti-outliers

## Context

Limiter edges irréalistes.

## Decision

Caps anti-outliers. Cette décision est valable tant que le site reste statique, Winamax-only
et orienté confiance dans les chiffres.

## Consequences

Quelques opportunités extrêmes peuvent être abaissées.
