# Glossaire Paris-Sportif

Ce glossaire donne les mots utiles pour lire le tableau, comprendre les risques et parler le meme langage que Winamax.

| Terme | Definition rapide | Exemple |
| --- | --- | --- |
| 1N2 | Resultat final domicile, nul ou exterieur. | Lyon gagne = 1. |
| Domicile | Equipe qui recoit. | PSG a domicile. |
| Exterieur | Equipe qui se deplace. | Marseille a l'exterieur. |
| Nul | Match termine a egalite. | 1-1. |
| Cote | Multiplicateur du pari. | 10 euros a 1.80 retourne 18 euros. |
| Mise | Montant engage sur le pari. | 5 euros. |
| Bankroll | Cagnotte reservee aux paris. | 100 euros dedies. |
| Edge | Avance du modele sur le marche. | Modele 60%, marche 53%. |
| EV | Gain moyen attendu. | +8% par euro joue. |
| ROI | Profit divise par mises totales. | +12 euros sur 100 euros = +12%. |
| CLV | Cote prise comparee a la cote de cloture. | Pris 2.10, cloture 1.95 = bon signe. |
| Closing line | Derniere cote avant le match. | Cote finale pre-match. |
| Value bet | Pari dont la cote paie trop. | Cote 2.20 pour proba juste 50%. |
| Kelly | Formule de taille de mise. | Kelly fractionne pour limiter le risque. |
| Kelly fractionne | Kelly reduit pour survivre a la variance. | 25% du Kelly brut. |
| Cap de mise | Limite maximale par pari. | 5% ou 10% de bankroll. |
| Drawdown | Perte depuis le plus haut de bankroll. | 100 -> 82 = -18%. |
| Variance | Fluctuation normale des resultats. | Perdre 4 bons paris de suite. |
| Brier | Score de calibration probabiliste. | Plus bas = mieux. |
| Calibration | Probabilites fideles au reel. | 70% annonce gagne environ 70 fois sur 100. |
| Confiance | Proba modele de reussite. | 68%. |
| Intervalle de confiance | Zone d'incertitude autour de la proba. | 65-72%. |
| Abstain | Le modele refuse de jouer. | Data trop faible ou signaux opposes. |
| Tier 1 Sur | Cotes basses, confiance haute. | 1.30-1.50. |
| Tier 2 Solide | Bon equilibre risque/gain. | 1.50-2.00. |
| Tier 3 Valeur | Cote plus haute avec edge. | 2.00-3.00. |
| Tier 4 Big odds | Gros gain, variance forte. | 3.00-5.00. |
| Tier 5 Outsider | Coup rare, risque maximal. | 5.00+. |
| DNB | Nul rembourse. | Si nul, mise rendue. |
| Handicap -0.5 | L'equipe doit gagner. | Equivalent victoire simple. |
| Handicap -1 | L'equipe doit gagner par 2+ buts. | 2-0 gagne. |
| Handicap +1 | L'equipe peut perdre d'un but selon regle du marche. | Protection outsider. |
| Handicap asiatique | Handicap avec remboursement possible. | -1 rembourse si victoire d'un but. |
| Double chance | Deux resultats couverts. | 1X = domicile ou nul. |
| 12 | Domicile ou exterieur, pas nul. | Evite le nul. |
| Over | Plus que la ligne. | Plus de 2,5 buts. |
| Under | Moins que la ligne. | Moins de 3,5 buts. |
| BTTS | Les deux equipes marquent. | Oui si 1-1. |
| Team total | Total de buts/points d'une equipe. | Rennes plus de 1,5 but. |
| Clean sheet | Equipe ne concede pas. | 1-0. |
| Score exact | Score final exact. | 2-1. |
| Mi-temps 1N2 | Resultat a la pause. | Domicile mene a la mi-temps. |
| Total mi-temps | Buts/points avant la pause. | Plus de 0,5 but HT. |
| Combiné | Plusieurs paris dans un ticket. | 3 selections. |
| Correlation | Dependence entre selections. | 1 + Over 2.5 meme match. |
| Anti-correlation | Selections plus independantes. | Sports differents. |
| Steam | Mouvement fort de cote. | 2.10 -> 1.80. |
| Sharp money | Mouvement suppose par joueurs informes. | Cote baisse sans bruit public. |
| Reverse line movement | Cote bouge contre le public. | Public favori, cote favori monte. |
| Market move | Variation de marche notable. | Plus de 10%. |
| Marge bookmaker | Difference entre probabilites et 100%. | Trop haute = marche cher. |
| Marché incertain | Cotes incoherentes ou marge anormale. | Home et away montent ensemble. |
| Signal rare | Angle peu frequent mais fort. | Voyage extreme + back-to-back. |
| Lookahead | Equipe pense deja au gros match suivant. | Rotation possible. |
| Letdown | Relachement apres gros match. | Apres derby ou coupe. |
| Fatigue | Calendrier lourd ou repos faible. | 3 matchs en 7 jours. |
| Voyage extreme | Deplacement long. | MLB/NHL avec 3000 km. |
| Back-to-back | Matchs deux jours de suite. | NBA/NHL/MLB. |
| Blessure severe | Absence importante. | Titulaire out. |
| Lineup | Composition probable ou confirmee. | Onze de depart. |
| Arbitre | Profil disciplinaire du match. | Cartons par match. |
| Meteo | Vent, pluie, temperature. | Vent fort favorise under. |
| xG | Buts attendus. | Qualite des occasions. |
| xGA | Buts attendus concédés. | Solidite defensive. |
| ELO | Niveau force equipe. | Rating dynamique. |
| H2H | Historique face-a-face. | 5 derniers matchs. |
| Forme L10 | Dix derniers matchs. | 7V 2N 1D. |
| Home/away split | Niveau domicile/exterieur. | Equipe forte chez elle. |
| Pace | Rythme basket/hockey. | Possessions ou volume. |
| Starter pitcher | Lanceur MLB probable. | Impact majeur total runs. |
| Goalie | Gardien NHL probable. | Save percentage. |
| Strikeouts | Retraits sur prises MLB. | Pitcher K. |
| Total runs | Total points baseball. | Plus de 8,5 runs. |
| F5 | Cinq premieres manches MLB. | First five innings. |
| Tiebreak | Jeu decisif tennis. | Oui/non. |
| Surface tennis | Terre, dur, gazon. | Profil joueur different. |
| Aces | Services gagnants tennis. | Over aces. |
| AUC | Pouvoir discriminant du modele. | <0.55 = prudence. |
| Sample | Taille d'echantillon. | n=100 plus fiable que n=8. |
| Watch | A surveiller, pas exploitable. | Data insuffisante. |
| Exploit | Angle actionnable. | Sample + ROI + Brier OK. |
| Low value | Gagne souvent mais paie mal. | 76% a 1.20 perdant long terme. |
| Void | Pari annule/rembourse. | Match reporte. |
| Live | Match en cours. | Cotes pre-match a ignorer. |
| No bet | Ne pas jouer. | Trop d'incertitude. |
| Timing | Moment conseille pour miser. | Attendre lineups ou jouer maintenant. |
| Profil Theo | Ajustement selon paris suivis. | Meilleur ROI sur cotes 1.80-2.50. |
| Discipline | Respect des mises et pauses. | Eviter tilt. |
| Tilt | Augmenter les mises apres pertes. | Comportement dangereux. |
| Heatmap P&L | Calendrier profit/perte. | Vert gain, rouge perte. |
| Score opportunite | Note 0-100 combinant edge, confiance et signaux. | 83 = spot prioritaire. |
