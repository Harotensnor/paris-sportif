🔍 Méthodologie

  • Source des cotes : Winamax exact (catalog official) — 100% des picks dans le sample.
  • Modèle : Bivariate Poisson + Dixon-Coles τ correction + Elo per-team + LightGBM stacking + ensemble adaptive weights v5.
  • Backtest : scripts/backtest_v2.py rejoue predictMatch sur events historiques via mini-racer (V8 embedded). Une seule source de vérité avec la prod.
  • Paper log : scripts/paper_trade_log.py snapshot des picks futurs + settle quand match completed. Forward proof immutable.
  • CLV : compute_clv.py compare cote au snapshot vs cote finale Winamax. Mesure si on bat le marché.
  • Stratégie default : FLAT 1u (1% bankroll). Kelly disponible mais documenté -30% ROI historique.
