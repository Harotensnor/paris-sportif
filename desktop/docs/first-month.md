# Premier mois avec Paris Sportif Desktop

Ce guide donne une routine simple pour utiliser l'app sans se disperser.

## Semaine 1 — Observer

- Ouvre l'app chaque matin.
- Lis le `TOP PICK`, puis les sections `Dans l'heure` et `Dans les 3 heures`.
- Ne joue que les cartes avec le format clair `PARI / COTE / MISE / Pourquoi`.
- Active le mode démo si tu veux tester sans toucher à ton suivi réel.

## Semaine 2 — Suivre proprement

- Clique `Je mise` uniquement quand tu places vraiment le ticket chez Winamax.
- Garde l'anti-tilt strict activé.
- Ajoute une note courte sur les paris importants.
- Vérifie le `Bilan` en fin de journée.

## Semaine 3 — Ajuster

- Regarde les segments gagnants et perdants dans `Bilan`.
- Désactive les sports ou marchés qui ne te conviennent pas.
- Compare `Modèle` et `Toi` pour voir si tu suis les picks fiables.
- Exporte ton profil une fois par semaine.

## Semaine 4 — Stabiliser

- Choisis une stratégie bankroll et garde-la pendant toute la semaine.
- Lis le rapport hebdo le lundi.
- Garde le Mode expert fermé sauf pour diagnostiquer un souci.
- Si les données semblent anciennes, lance un refresh puis attends le bandeau de fin.

## Règle d'or

Le logiciel doit t'aider à choisir moins vite mais mieux. Si tu ne comprends pas un pari en trois secondes, ne le joue pas.
